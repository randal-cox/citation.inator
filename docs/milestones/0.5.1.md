## Delivered

Implemented in the working candidate: one configured marker keyword, default `cite`, for works/endnotes/lists/nocite/evidence/credit. No implicit `citation`, work-only alias under custom keywords, or unnamespaced `{endnotes}` fallback. An explicitly configured keyword remains supported. Cache schemas, component/API names and CSS/data contracts are unchanged.

Learning work: website-maintenance justification and headline features; a Citation/JavaScript/HTML tabbed minimal example; one shared split footer with name/ORCID left and license/software citation right. The footer hover uses the library's own credit annotation. Reading-button check dates move below buttons in compact ISO format. Card title styles no longer indent bold text inside excerpts. Every intro points to Source/JavaScript/HTML; metadata-driven recipes show their actual fields in complete JavaScript. Relevant JS/HTML disclosures open side by side above uniform arrow download buttons. Advanced recipes are grouped at the bottom; small access-option sets stay visible, and return controls have an arrow, mention letter and divider.

The preview.1 revision adds a compact localized Reading services gear pill for the same settings workflow and unifies the learning selectors with one vector chevron.
