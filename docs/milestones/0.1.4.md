# Milestone 0.1.4 — We have a citation for that

**Completed and released on 18 November 2026.**

The [GitHub release](https://github.com/randal-cox/citation.inator/releases/tag/v0.1.4) is tagged `v0.1.4` at commit `f93b1c4a72a83e89ee8f8fe38b13e0c872986da4`. The release includes the npm tarball, standalone HTML ZIP and SHA-256 checksums.

## Delivered

- Reader profiles distinguish unknown settings from no services selected. Profiles persist locally, synchronize inspectors, and support built-in or host-owned settings.
- Locations carry explicit copy-level access. Open copies appear first, selected services follow, and other destinations collapse behind a count.
- Preferred title links identify their destination visibly and accessibly. Copied citations and exports retain the work's canonical bibliographic identity.
- Service catalogues, configurable wording and plural rules support host customization. Library access supports proxy and OpenURL links.
- Structured occurrences and trigger bindings support app-rendered citations, stable IDs, repeated references, updates, cleanup and focus return.
- Host appearance controls and explicit dismissal support themes, dialogs and navigation. Webpage references include their canonical URL.
- Artwork and image records preserve attribution, date ranges, medium, institution, accession, rights, contributors and separate source/served checksums.
- Compact inspect controls can precede a reference. Custom icon masks follow text colour, and empty trailing action boxes are omitted.
- The Reading room, Plain HTML, Guide, README and packaged guides demonstrate and document the additions.

## Acceptance and evidence

The adopting site's reviewer reported successful tests against a scratch copy, reading lists matching its live presentation, and citation panels opening without errors. It verified both compact-action fixes and removed its icon-swapping workaround. This is adopter-reported evidence.

The release candidate passed all 51 tests on Node 22.23.3 and the full Chrome 157.0.8103.78 suite. The checks covered the compiler, CLI, package, copied standalone assets, no-JavaScript references, access profiles, host settings, media records, clipboard output, light/dark masks, CSP, keyboard focus, touch emulation and nested-dialog dismissal.

Independent adversarial reviews covered distribution, versioning, testing, UX/accessibility, documentation, roadmap, citation/authorship and non-sequitur concerns. All passed within their recorded scope. The [verification history](../reader-preview-verification.md) retains the candidate checks, fixes and reviewer verdicts. The [recurring adversarial plan](../adversarial-testing.md) applies at future milestones and when changes warrant it.

## Known limits and follow-up

- Unknown-profile help currently appears under each reading. An adopter with 30 readings sees it repeatedly. Show the help once per list and retain a settings entry in each inspector.
- Hosts adding content such as Theory/Praxis tags need a documented before-item insertion hook. The adopter repaired its exact-markup matching, and a library hook remains proposed.
- Chicago is the initial media formatting target. Other citation presets use the documented [generic media fallback](../media-support.md#formatting-support).
- Native Safari, VoiceOver and physical-phone verification remains open. Chromium emulation provides narrower evidence.
- The comprehensive citation-style catalogue remains planned. Its scope and the larger feature wishlist are retained in the [roadmap](../../ROADMAP.md).

The two adopter suggestions were accepted as nonblocking follow-up work. They were carried forward when the milestone was closed.
