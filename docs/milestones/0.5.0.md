# Milestone 0.5.0 — Developer learning and live demos

**Active, authorized 23 November 2026 after final 0.4.0 adopter sign-off.** The maintainer first requested this track on 20 November 2026. Build a public learning site with a live browser playground, progressive tutorials and annotated examples.

Developers should learn by editing working examples that connect visible output, source notation and configuration. The checklist below is the scope; the linked coverage matrix tracks individual features.

The public preview runs on [GitHub Pages](https://randal-cox.github.io/citation.inator/). Local compiling/parsing and saved provider fixtures keep core demonstrations usable without a backend or credentials. Live provider lookup remains subject to browser/provider constraints. Deployment, UI-language and clean-download checks pass; adopter tutorial acceptance and the final library release remain pending.


## Work checklist and sequence

Checked items are implemented and locally exercised; release/adopter/deployment acceptance is recorded separately below. Routine layout and implementation decisions do not need a new scope approval.

- [x] Progressive quick start: load/init first; compile one citation; add endnotes and the inspector; explain the notation alongside the rendered result.
- [x] Editable browser playground: source, structured reference data and configuration connected to live output; reset controls and complete examples.
- [x] Feature tutorials: five styles and their limits, CSS/namespaces, titles/icons, hover/click/panel movement, keyboard/accessibility, formatted references, locators/prefixes, original/reprint years and year letters.
- [x] Advanced examples: reader access/privacy and services, artwork/media/rights/provenance, evidence/credit, editor notes, tags/filters and shared/cross-page bibliographies.
- [x] Import walkthrough: paste/text/Markdown/PDF/DOCX/ODT intake, bibliography/source evidence, ambiguous/unmatched decisions, DOI/ISBN proposals and edition choices, local/identifier-free completion, converted Markdown/cache downloads. Saved DOI examples are deterministic; edition discovery is demonstrated in the separate live host and the accepted baseline browser fixtures.
- [x] Runnable downloads: minimal npm and non-npm projects, static-site/build recipes and source links tied to their library version. Clean npm, copied-file and whole-site extraction runs pass locally.
- [x] Worked host/draft integration: host appearance, source revisions, explicit review, undo/transactions and persistence; uses unmodified accepted draft code. Adopter tutorial review remains pending.
- [x] UI translation/i18n: configurable labels, real plural rules, locale-aware values, English fallback and an example translation. Host appearance remains distinct from language; this does not promise exhaustive international citation-manual conformity.
- [x] Public static learning site: GitHub Pages deployment workflow with correct project-base paths, local compiling/parsing and saved provider fixtures. Published assets/links and clean downloads verified; live provider behavior is distinct from fixture output.
- [ ] Coverage and acceptance: maintain [the feature/example matrix](../learning-coverage.md), teach failures/offline/stale cases, test clean downloads and keyboard/touch/narrow layouts, and run the standard milestone/adversarial procedure.

Version 0.6.0 retains bibliography-manager connections and source maintenance. The separate bibliography-auditor product remains a research revisit. Neither is a prerequisite for the learning site.

The learning preview is published as `0.5.0-preview.0`; a final 0.5.0 library release is not published. Stable release artifacts remain 0.4.0 and immutable.
