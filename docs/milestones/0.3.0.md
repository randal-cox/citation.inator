# Milestone 0.3.0 — Editor integration and reader polish

**Completed and released on 21 November 2026.** On 21 November 2026 the maintainer removed the large import scope from this milestone so draft.inator can adopt a published editor-tools release. Published version is now 0.3.0. Import prototypes are preserved separately for [0.4.0](0.4.0.md); [0.5.0](0.5.0.md) covers comprehensive learning/docs and [0.6.0](0.6.0.md) bibliography connections.

## Delivered scope

- `markerKind` classifies complete canonical/legacy/custom-keyword markers using the compiler grammar, exported by tools and both browser bundles.
- `annotateMarkers` supports opt-in `noteContext: "work"` matching standalone descriptions. Default article notes and reader-facing year letters remain unchanged.
- `referenceItemPrefix` supplies cloned metadata to a synchronous escaped-text host callback before reference items.
- Unknown-profile access help appears once per owned list; inspector settings remain available. Component boundaries and save/clear focus behavior are tested.
- Current-feature API/CLI/integration documentation and a citation-style catalogue/support matrix. The comprehensive pedagogical expansion is separate 0.5.0 work.

## Excluded scope

No native document import, in-text matcher/reference parser, Crossref bibliographic search, review/edit protocol or import-review demo is promised by the 0.3.0 package. Existing development work remains on the import branch for 0.4.0 and is not discarded. Embedded Zotero metadata preservation belongs to import 0.4.0; external manager connections belong to 0.6.0.
