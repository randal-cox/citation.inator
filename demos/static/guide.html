Citation guide

See the markup behind the reading room, then use the same notation in your own document.

Load and initialize

Download or clone the repository. Run npm start from the checkout to serve the demos, then open the Plain HTML example.

cd citation.inator
npm start

Without npm, serve the prebuilt demos/drop-in/ directory or extracted ZIP with any static server. The standalone README includes a Python command.

Copy dist/citation-inspector.mjs, its adjacent dist/citation-inspector.css, and dist/LICENSE to your site. To build the current npm tarball, run npm ci then npm pack in the downloaded repository. That tarball includes the same browser assets under node_modules/citation-inator/dist/. Serve the compiled citation fragment and its cache from the same origin. The module registers the element when it loads.

<link rel="stylesheet" href="./citation-inspector.css">
<script type="module" src="./citation-inspector.mjs"></script>

<citation-inspector data-cache="./citations.json" class-prefix="my-site-citation">
  <!-- Paste the compiled HTML fragment here. -->
</citation-inspector>

Set options on the element or in your site's browser module. The default classes start with citation-. Use class-prefix or classPrefix to give them your own prefix.

import { initializeCitationInspector } from "./citation-inspector.mjs";

initializeCitationInspector(document.querySelector("citation-inspector"), {
  classPrefix: "my-site-citation",
  activation: "hover",
  panelTitle: "Source details",
  panelIcon: "/assets/logo.svg",
  evidenceTitle: "Metadata trail",
  evidenceIcon: "/assets/evidence.svg",
  creditTitle: "Software credits",
  creditIcon: "none",
  accessProviders: ["WorldCat", "Open Library"],
  hiddenAccessProviders: ["JSTOR"]
});

The matching HTML attributes are panel-title, panel-icon, evidence-title, evidence-icon, credit-title, credit-icon, access-providers, and hidden-access-providers. Icons use a same-origin URL, the built-in mark, or none. The open attribute is present on the host while any panel is visible.

To compile plain text directly from the checkout with Node.js 22 or later, run this from the repository root. The CLI writes article.html and article.html.json.

node scripts/compile.mjs --style chicago-author-date --endnotes-heading References \
  demos/drop-in/reading.txt demos/drop-in/citations.json article.html my-article

Using the demo

Use CSS to change the appearance of citation content and Style to change citation and endnote formatting. The help buttons beside the settings show the matching code. The demo also chooses References or Works Cited for named styles. Set endnotesHeading separately in your own site.

Click a reference to inspect it. Enable Hover to preview citations, evidence, and credit with the mouse. To reposition the panel, choose Move panel from the three-dot menu and click or tap the destination. You can also drag from a blank area. You can still select text and use links and buttons. When the panel opens from a click or keyboard activation, its heading has focus. Use the arrow keys to move it or Home to reset. Press Escape or click or tap outside to dismiss it. Each lettered return link in the endnotes leads to its own occurrence. Its tooltip identifies the surrounding text.

On the Resolution bench, enter an identifier or choose a sample. The prefilled ISBN and its displayed citation come from the bundled cache. Resolve uses that record locally. Force refresh asks Crossref for a DOI or Open Library for an ISBN. Open Citation evidence to see the provider response and how the result was assembled.

Open this journal article citation {citation doi:10.1017/S0003055419000534} to see links to the publisher’s version and the author’s preprint.

The narrative form puts {citation isbn:9780593656433 | form:narrative} directly in the sentence. That citation links to a hardcover edition. The next citation points to a dissertation PDF in a university repository {citation frost-2020-modern-not-meaningless}.

A reading list can hold several kinds of evidence side by side {citation doi:10.1017/S0003055419000534; doi:10.1111/spc3.12501}.

Try a page locator on Molly Farneth’s print edition {citation isbn:9780691198927 | locator:34}. Open the citation to see two library services for the print edition.

Related reading can share the same parentheses {citation isbn:9780691198927; isbn:9780593656433 | prefix:see also | locator:"p. 34"}. The lettered links in Farneth’s endnote return to each mention.

For an explicit parenthetical citation, use Farneth’s book {citation isbn:9780691198927 | form:parenthetical}. If you have already written Farneth’s name, you can show just the year {citation isbn:9780691198927 | form:suppress-author}.

{citation isbn:9780691198927 | form:author-only} can also appear by name alone in a sentence. A parenthetical aside can give just the name {citation isbn:9780691198927 | form:suppress-year}.

Here is a marker displayed as literal text: \{citation endnote\}. In the source, a backslash before each brace keeps it from inserting endnotes. A custom label can point to {citation doi:10.1017/S0003055419000534 | label:"the study | journal article; preprint available"}. An unresolved reference can display its supplied fallback {citation local:unresolved-ritual-politics-reconciliation-2022 | ritual and reconciliation reference pending}.

PubMed {citation pmid:16060722} and PubMed Central {citation pmcid:PMC1182327} lead to the same article. Its bare DOI {citation 10.1371/journal.pmed.0020124} and DOI URL {citation https://doi.org/10.1371/journal.pmed.0020124} share the same endnote.

Other sources can use an arXiv ID {citation arxiv:1706.03762}, a dataset DOI {citation dataset:10.6073/pasta/98b16d7d563f265cb52372c8ca99e60f}, a software DOI {citation software:10.5281/zenodo.3960218}, or a URL {citation url:https://zenodo.org/records/3960218}.

{citation isbn:9780593656433 | form:narrative}
A cached ISBN with the author in the sentence and the year in parentheses.
{citation doi:10.1017/S0003055419000534; doi:10.1111/spc3.12501}

{citation isbn:9780691198927; isbn:9780593656433 | prefix:see also | locator:"p. 34"}
Add a prefix and a locator to one item in a group. A bare page number adapts to the selected style.
{citation doi:10.1017/S0003055419000534 | label:"the study | journal article; preprint available"}
Choose the visible label. Quotes protect literal pipes and semicolons.
{citation local:unresolved-ritual-politics-reconciliation-2022 | ritual and reconciliation reference pending}

{citation isbn:9780691198927 | form:parenthetical}
Put the author and year in parentheses. This is the default.
{citation isbn:9780691198927 | form:author-only}
Show only the author, without parentheses.
{citation isbn:9780691198927 | form:suppress-author}
Show only the year, in parentheses.
{citation isbn:9780691198927 | form:suppress-year}
Show only the author, in parentheses.
{citation endnote}
Place the endnotes on their own paragraph. The compiler appends them when the marker is absent.
{citation evidence}
Show cited source metadata or the Resolution bench’s provider evidence.
{citation credit}
Show the software credit, license and suggested citation.

The reading also demonstrates doi:, isbn:, pmid:, pmcid:, arxiv:, url:, dataset:, software:, a recognized HTTPS URL or an ID from the local cache. Bare DOIs also work. A missing record is marked unresolved.

Keep each directive on one line. To display {citation endnote} as literal text, put \{citation endnote\} in the source. Inside a directive, a backslash escapes a semicolon, pipe, quote, brace or backslash. Legacy {cite …} and {endnotes} also work. Expand Custom keyword and legacy notation below the reading in either demo to see both rendered alongside their source.

Set your keyword

With citationKeyword: "ref", write {ref DOI}, {ref endnote}, {ref evidence}, and {ref credit}. The keyword and class prefix accept 1–32 lowercase ASCII letters, digits or hyphens, starting with a letter. Use the same class prefix in the browser if you initialize it separately.

import { createCitationCompiler } from "citation-inator";

const compiler = createCitationCompiler({
  citationKeyword: "ref",
  classPrefix: "my-site-citation",
  citationStyle: "chicago-author-date",
  endnotesHeading: "References"
});
const result = compiler.compile(
  "{ref isbn:9780593656433}\n\n{ref endnote}", cache, { namespace: "article-one" }
);

Styles and existing markup

Choose chicago-author-date, apa, mla, harvard (Cite Them Right), vancouver, or default. The named styles cover common books and journal articles. Set endnotesHeading to a heading such as References or Works Cited.

In Chicago author–date, set the same id on an author in each record to identify a single person across bylines such as Richard Wrangham and Richard W. Wrangham. The bibliography keeps each record’s spelling.

Keep the default suffixScope: "fragment" for articles with independent reference lists. Use suffixScope: "cache" for pages that share one bibliography, such as chapters of an online book. The compiler reports when a year letter in a page’s endnotes has a companion work outside those endnotes.

With npm dependencies installed, compile trusted HTML or Markdown using citation-inator/markup, or pass --format html or --format markdown to the CLI. Each directive must stay inside one text node. Use a distinct namespace for each copy of a fragment on the same page.

import { compileHTML, compileMarkdown, rebaseCitationFragment } from "citation-inator/markup";

const options = { namespace: "essay", citationStyle: "chicago-author-date", endnotesHeading: "References" };
const result = compileHTML("<p><em>Consent</em> has a history {citation local:consent}.</p>", cache, options);
const anotherCopy = rebaseCitationFragment(result.html, "essay", "essay-copy");
// For Markdown sources, call compileMarkdown(source, cache, options).

For a build tool such as Python, run the CLI with --json and send { paragraphs, cache, options } on standard input. It returns { html, cache, diagnostics }. For HTML or Markdown send { source, format, cache, options }.

Format references and add access links

For curated reference text, put citationParts on the record. Each part has text and optional emphasis set to "italic" or "bold". Both the inspector and endnotes display the formatting.

Supply record locations with kind: "library" or kind: "full-text", a provider name and an HTTPS URL. Pass the reader’s preferred provider names in order using accessProviders. Set hiddenAccessProviders to hide services in the panel and endnotes. The application can reuse its own preference settings.

Use originalIssued: [1912] and issued: [1995] to store both dates for a translated or reprinted work. Try the Durkheim citation in the reading room with Chicago and APA selected.

The integration guide shows how to find ISBN candidates by title and author and review them before updating a cache.
