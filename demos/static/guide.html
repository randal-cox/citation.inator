Citation guide

See the markup behind the reading room, then use the same notation in your own document.

Load and initialize

Without npm, download or clone the repository and serve the prebuilt demos/drop-in/ example. Open the local example after starting the server. The standalone ZIP works the same way.

cd citation.inator/demos/drop-in
python3 -m http.server --bind 127.0.0.1 8080

Copy dist/citation-inspector.mjs, its adjacent dist/citation-inspector.css, and dist/LICENSE to your site. To build the current npm tarball, run npm ci then npm pack in the downloaded repository. That tarball includes the same browser assets under node_modules/citation-inator/dist/. Serve the compiled citation fragment and its cache from the same origin. The module registers the element when it loads.

<link rel="stylesheet" href="./citation-inspector.css">
<script type="module" src="./citation-inspector.mjs"></script>

<citation-inspector data-cache="./citations.json" class-prefix="my-site-citation">
  <!-- Paste the compiled HTML fragment here. -->
</citation-inspector>

Set options on the element or in your site's browser module. The default classes start with citation-. Use class-prefix or classPrefix to give them your own prefix.

import { initializeCitationInspector } from "./citation-inspector.mjs";

initializeCitationInspector(document.querySelector("citation-inspector"), {
  classPrefix: "my-site-citation",
  activation: "hover",
  panelTitle: "Source details",
  panelIcon: "/assets/logo.svg",
  evidenceTitle: "Metadata trail",
  evidenceIcon: "/assets/evidence.svg",
  creditTitle: "Software credits",
  creditIcon: "none",
  accessProviders: ["WorldCat", "Open Library"]
});

The matching HTML attributes are panel-title, panel-icon, evidence-title, evidence-icon, credit-title, credit-icon, and access-providers. Icons use a same-origin URL, the built-in mark, or none. The open attribute is present on the host while any panel is visible.

To compile plain text directly from the checkout with Node.js 22 or later, run this from the repository root. The CLI writes article.html and article.html.json.

node scripts/compile.mjs --style chicago-author-date --endnotes-heading References \
  demos/drop-in/reading.txt demos/drop-in/citations.json article.html my-article

Using the demo

Use CSS to change the appearance of citation content and Style to change citation and endnote formatting. The help buttons beside the settings show the matching code. The demo also chooses References or Works Cited for named styles. Set endnotesHeading separately in your own site.

Click a reference to inspect it. Enable Hover to preview citations, evidence, and credit with the mouse. To reposition the panel, choose Move panel from the three-dot menu and click or tap the destination. You can also drag from a blank area. You can still select text and use links and buttons. When the panel opens from a click or keyboard activation, its heading has focus. Use the arrow keys to move it or Home to reset. Press Escape or click or tap outside to dismiss it. Each lettered return link in the endnotes leads to its own occurrence. Its tooltip identifies the surrounding text.

On the Resolution bench, enter an identifier or choose a sample. Resolve can reuse a fresh cache. Force refresh asks Crossref for a DOI or Open Library for an ISBN. Open Citation evidence to see the provider response and how the result was assembled.

Complete notation

{citation doi:10.1017/S0003055419000534}
An inline author–year citation. Replace DOI with an identifier or a local record key.
{citation DOI; ISBN}
Group parenthetical citations. A semicolon separates items.
{citation DOI | prefix:see also | locator:"p. 34"}
Add words before the citation and supply a locator. A bare number adapts to the selected style.
{citation DOI | label:"the study"}
Supply the words readers see. Quoted labels can contain pipes and semicolons.
{citation DOI | fallback words}
Supply the text to show when the identifier cannot be resolved.
{citation DOI | form:parenthetical}
Author and year inside parentheses. This is the default.
{citation DOI | form:narrative}
Author in the sentence, followed by the year in parentheses.
{citation DOI | form:author-only}
Author with no date and no parentheses.
{citation DOI | form:suppress-author}
Year alone in parentheses.
{citation DOI | form:suppress-year}
Author alone in parentheses.
{citation endnote}
Place the bibliography. Give it its own paragraph. The compiler appends endnotes when this marker is absent.
{citation evidence}
Show cited source metadata or the Resolution bench’s latest provider response and merge decisions when available.
{citation credit}
Show the software credit, license and suggested citation.

Use doi:, isbn:, pmid:, pmcid:, arxiv:, url:, dataset:, software:, a recognized HTTPS URL or an ID from the local cache. Bare DOIs also work. A missing record is marked unresolved.

Keep each directive on one line. Use a backslash to escape literal braces. Inside a directive, a backslash escapes a semicolon, pipe, quote, brace or backslash. Legacy {cite …} and {endnotes} also work.

Set your keyword

With citationKeyword: "ref", write {ref DOI}, {ref endnote}, {ref evidence}, and {ref credit}. The keyword and class prefix accept 1–32 lowercase ASCII letters, digits or hyphens, starting with a letter. Use the same class prefix in the browser if you initialize it separately.

import { createCitationCompiler } from "citation-inator";

const compiler = createCitationCompiler({
  citationKeyword: "ref",
  classPrefix: "my-site-citation",
  citationStyle: "chicago-author-date",
  endnotesHeading: "References"
});
const result = compiler.compile(
  "{ref isbn:9780593656433}\n\n{ref endnote}", cache, { namespace: "article-one" }
);

Styles and existing markup

Choose chicago-author-date, apa, mla, harvard (Cite Them Right), vancouver, or default. The named styles cover common books and journal articles. Set endnotesHeading to a heading such as References or Works Cited.

With npm dependencies installed, compile trusted HTML or Markdown using citation-inator/markup, or pass --format html or --format markdown to the CLI. Each directive must stay inside one text node. Use a distinct namespace for each copy of a fragment on the same page.

import { compileHTML, compileMarkdown, rebaseCitationFragment } from "citation-inator/markup";

const options = { namespace: "essay", citationStyle: "chicago-author-date", endnotesHeading: "References" };
const result = compileHTML("<p><em>Consent</em> has a history {citation local:consent}.</p>", cache, options);
const anotherCopy = rebaseCitationFragment(result.html, "essay", "essay-copy");
// For Markdown sources, call compileMarkdown(source, cache, options).

For a build tool such as Python, run the CLI with --json and send { paragraphs, cache, options } on standard input. It returns { html, cache, diagnostics }. For HTML or Markdown send { source, format, cache, options }.

Format references and add access links

For curated reference text, put citationParts on the record. Each part has text and optional emphasis set to "italic" or "bold". Both the inspector and endnotes display the formatting.

Supply record locations with kind: "library" or kind: "full-text", a provider name and an HTTPS URL. Pass the reader’s preferred provider names in order using accessProviders. The application can reuse its own preference settings.

The integration guide has complete record, Python and ISBN resolver examples.
