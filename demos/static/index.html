Reading room Resolution bench Plain HTML Guide

Follow the source.

Open a citation in the reading below to inspect its source. The endnotes also work when JavaScript is off.

initializeCitationInspector(element, { activation: "hover" }) <citation-inspector data-citation-theme="reading">Use with demos/static/demo.css. For a custom theme, set the --citation-* properties on the element. createCitationCompiler({ citationStyle: "default" })

Citation examples

Open this journal article citation (Simas et al., 2020) to see links to the publisher’s version and the author’s preprint.

The narrative form puts Feiler (2026) directly in the sentence. That citation links to a hardcover edition. The next citation points to a dissertation PDF in a university repository (Frost, 2020).

A reading list can hold several kinds of evidence side by side (Simas et al., 2020; Feinberg & Willer, 2019).

Try a page locator on Molly Farneth’s print edition (Farneth, 2023, 34). Open the citation to see two library services for the print edition.

Related reading can share the same parentheses (Farneth, 2023; see also Feiler, 2026, p. 34). The lettered links in Farneth’s endnote return to each mention.

For an explicit parenthetical citation, use Farneth’s book (Farneth, 2023). If you have already written Farneth’s name, you can show just the year (2023).

Farneth can also appear by name alone in a sentence. A parenthetical aside can give just the name (Farneth).

Write {citation endnote} to show the marker as literal text. A custom label can point to the study | journal article; preprint available. An unresolved reference can display its supplied fallback (ritual and reconciliation reference pending).

PubMed (Ioannidis, 2005) and PubMed Central (Ioannidis, 2005) lead to the same article. Its bare DOI (Ioannidis, 2005) and DOI URL (Ioannidis, 2005) share the same endnote.

Other sources can use an arXiv ID (Vaswani et al., 2017), a dataset DOI (Palmer Station Antarctica LTER & Gorman, 2020), a software DOI (Horst et al., 2020), or a URL (Horst et al., 2020).
