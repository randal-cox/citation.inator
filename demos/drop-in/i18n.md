# UI language and messages

Pass `locale` and `strings` to the compiler **and** inspector. The Node compiler, browser compiler, tools bundle and reader bundle share the same catalogues.

```js
const options = {
  locale:'es',
  strings:{'access.more':{one:'{countLabel} más',other:'{countLabel} más'}}
};
const result = compileMarkdown(source, cache, options);
initializeCitationInspector(element, {...options, cache:result.cache});
```

English (`en`) is the fallback. Spanish (`es`) is the example translation. A valid unsupported language tag keeps English messages while using the requested `Intl` number, date and plural rules. Invalid language tags or non-text overrides throw `TypeError`. Partial overrides fall back per plural category; instances snapshot their overrides and do not change shared catalogues.

```js
import {createCitationMessages, citationLocales} from 'citation-inator/i18n';
const messages = createCitationMessages({locale:'de-DE'});
messages.number(12345.6); // 12.345,6
messages.date(new Date('2026-11-23T12:00:00Z'), {
  year:'numeric',month:'long',day:'numeric',timeZone:'UTC'
});
console.log(Object.keys(citationLocales.en));
```

The helper and catalogues are also exported by the self-contained browser reader, compiler and tools bundles. `text(key, values)` interpolates text once. It does not escape HTML: use DOM `textContent` or escape at an HTML sink. The library follows that rule internally. A missing unknown key returns the key so an incomplete integration remains inspectable.

Plural messages accept `zero`, `one`, `two`, `few`, `many` and `other`; categories follow `Intl.PluralRules(locale)`. Supply a numeric `count` for selection. `{count}` is the raw supplied value; `{countLabel}` is automatically formatted for the locale, unless explicitly overridden. Built-in count messages use `countLabel`. Other placeholders, such as `service`, `label`, `title`, `date` and `total`, remain caller-supplied text.

## Scope and precedence

Messages cover library-generated inspector controls, access settings, static endnotes/reading-list controls, evidence/credit, return labels, empty states and count labels. A configured `endnotesHeading`, marker-authored heading, panel title, tag label or service name remains authored text. Source titles, authors, abstracts and bibliographic style conventions are not translated. Citation language and citation-manual conformance are separate concerns.

Configure language before insertion for a consistent first render. Reconfiguring the inspector updates its generated controls, labels and open access-settings labels while preserving unsaved settings fields. Static compiled text requires recompilation; an inspector cannot infer which static authored text should change. Recompile with the same locale/options rather than replacing strings in generated HTML. The component sets `lang` on its dialogs; host documents own page language/direction and appropriate fonts. RTL visual acceptance is not claimed by the Spanish example.

The learning shell, import demonstration host, CLI diagnostics prose and provider responses remain English. Diagnostic codes and record data remain stable. Hosts can translate their own review interface around the headless API. This release does not claim complete locale coverage or translation of external material.

Common overrides include `ui.inspect`, `ui.inspectCitation`, `ui.endnotes`, `ui.panelOptions`, `ui.move`, `ui.return`, `ui.filterLegend`, `ui.shown`, `access.settings`, `access.save`, `access.cancel` and `access.more`. Inspect `citationLocales.en` for the complete authoritative key list.
